# Actividad 2: Juego Pac-Man 👻

## Contenido

Este repositorio cuenta con el código en Python del juego **Pac-Man**, utilizando las librerías `random`, `turtle` y `freegames`.

Se agregaron 3 cambios respecto al código original:

- Haciendo a los fantasmas "mas listos#.
- Cambiando el mapa.
- Aumentando la velocidad de los fantasmas

## Objetivo

Modificar el repositorio utilizando el control de versiones de **Git** y funciones de **GitHub** como *fork* y *pull requests*.
